# 美林 · 超级导演源码来源

原型版本：本地项目 `fg-director-agent`，commit `3834e91`（v0.4.2）。本目录从该版本的 Git 跟踪文件建立源码快照；原型仓库保持只读，没有向其提交或推送。

`upstream/` 保留白色界面、小球、剧集管理、记忆、资产、导演提示词与后期流程，并在 FG 副本中适配身份、权限、持久化、模型、任务、报价和费用。

没有导入原型 `.env`、运行数据、上传、个人配置、node_modules 或构建产物。外部技能包不随该源码快照分发，生产通过只读目录挂载完整包；原有 `CREDITS.md` 和署名保留。

运行依赖沿用 React、Three、Vite，增加与 FG 网关相同版本的 `pg`。免费 SQL 验收使用开发依赖 PGlite，不进入生产依赖和运行镜像。
