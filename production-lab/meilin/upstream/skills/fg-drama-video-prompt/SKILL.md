# FG 文戏导演（视频提示词）

本 Skill 派生自 Work-Fisher 公开的 `script-to-drama-prompt-dev`（剧情转折分段、声线锁定、画外音承接、插入镜头与空镜规则），按 FG 制作要求改为下方的 FG 标准输出格式，并新增"段间衔接锁"。原作署名与来源见本目录 `CREDITS.md`。

## 0. 输入

每次生成必须拿到：

1. **剧集圣经**：画风、演员面孔/地域、台词语言、表演风格、画幅帧率、视频模型及其单段时长上限、色彩基调。
2. **本集已确认剧本**（逐字保留台词与原作 OS）。
3. **资产表**：角色/场景/道具的编号与通过状态（如 `@角色1 艾拉`、`@场景2 雨夜公寓走廊`）。
4. **上一段衔接锁**（第一段为空）。

缺少圣经或剧本时先要，不自行编造人物外观。

## 1. 分段

- 按"关系状态发生一次可见变化"切分；一段只承载一个主场景、一个关系变化、一个明确出口。
- 时长取圣经的单段时长（默认 15 秒，可选 5–30 秒且不超过模型上限）。台词量参考：中文约每秒 4 字、英文约每秒 2.5 词，超出就在关系转折处拆段，禁止靠加速硬塞。
- 不在一句完整台词中间切段。
- 先输出分段大纲（段号、时长、一句话事件与结尾落点、出场资产），成员确认后再逐段写提示词。

## 2. 输出格式（逐段，字段顺序与标题固定）

```text
[项目名称]
[总时长]秒｜[一镜到底／多镜头]｜[类型与表演风格]

【视频整体概念】
类型：…
表演风格：…
时长：…秒。
画幅与帧率：…
剪辑方法：…（一镜到底写完整摄影机路线与穿越的真实通道；多镜头写切点与前后承接）
时间与天气：…
地点：…（环境、边界、出入口、关键道具、通行路线）
整体叙事：起始状态 → 触发事件 → 人物行动 → 变化或发现 → 结束状态。

【参考图绑定】
人物A严格参考：@角色N。锁定面部身份、发型、体型、服装、标志性配饰和关键道具。
…
场景／道具／色彩参考：@场景N、@道具N 及各自用途。
人物全程保持各自身份；快速运动、遮挡、短暂失焦后仍是同一面部、发型、服装和道具状态。
说明哪些内容继承，哪些仅作气质参考。

【摄影参数与镜头控制】
镜头 / 景深 / 机位 / 运动路径（为什么动、何时动、速度、落点）/ 转向节奏 / 稳定性 / 焦点控制 / 曝光与白平衡（按需）

【画面整体视觉方向】（一段完整文字）

【真实皮肤／主体材质】

【画面色彩与逻辑】主色 / 辅色 / 强调色 / 饱和度与明暗 / 连续性

【光影】主光源 / 环境反射 / 面部与身体 / 空间层次 / 随动变化

【背景人物活动】

【主角的眨眼与错时表演】眨眼 / 视线 / 转向 / 停步 / 表情 / 双人反应 / 道具互动

【[总时长]秒分镜／动作时间轴】
[起]—[止]秒｜[本段叙事任务]
人物动作：…
镜头运动：…
背景：…
（覆盖到结尾；按动作分配时间，不必均分；最后一段写清人物、镜头和信息停在什么状态）

【声音设计】音乐 / 环境底声 / 人群声音 / 人物近声 / 现场细节声 / 电子声 / 空间关系 / 对白（角色、台词原文、说话时机）

【负面约束】身份 / 动作 / 空间 / 摄影 / 画面 / 声音 / 其他
```

格式规则：

- 人物在正文里用固定代号（A、B…），代号与 `@角色N` 的对应只在【参考图绑定】写一次，全段一致；摄影机写作 C。
- 时间轴每一小段都写三件事：**人物动作**（位置、朝向、视线、动作先后、互动、结束位置）、**镜头运动**（位置、高度、距离、路线、速度、构图变化、焦点交接）、**背景**（可见空间、环境动作、背景人物反应、关键道具状态）。
- 导演思维写法：动作有先后（先看到 → 再转头 → 肩膀跟随），交接有条件（"A 确认 B 托住后松开右手"），镜头运动有动机（跟随、揭示、让出空间），失焦有触发（靠近、转身、遮挡）。

  示例（A、B 为人物，C 为摄影机）：
  > 16—18秒｜A、B 与镜头共同穿越警戒线
  > 人物动作：A 右手抬起警戒线，同时屈膝、低头、收下巴，先迈右脚再迈左脚通过。B 用左手从后方接住警戒线；A 确认 B 托住后松开右手。B 保持警戒带抬高，低头跟随通过。
  > 镜头运动：镜头 C 与 A 同步下降至约 1.2 米，从 A 抬出的真实空隙中后退穿过。警戒带斜向掠过画面并短暂虚化。通过后 C 缓慢上升，同时向右漂移，焦点由 A 低头的脸转向她的肩背。
  > 背景：制服警察侧身让出通道；一名取证人员拍摄地面，另一人将证物袋递给同事。

- **台词随视频生成**：对白逐字写进【声音设计 · 对白】并在时间轴对应位置标注说话时机；语言按圣经（海外剧默认英文原文，可在括号附中文意思供成员核对，不进入画面）。原作 OS 保留为 `A（OS）："…"`。
- **音乐和字幕后期加**：【声音设计 · 音乐】固定写"不生成音乐，后期添加"；【负面约束 · 其他】固定写"画面不出现字幕、文字、水印、Logo"。
- 曝光参数、背景人物等字段按需要填写；确实不适用时写"无"，不删除字段标题。

## 3. 段间衔接锁（新增，必须执行）

**每段写完后**，在提示词正文之外输出一个"衔接锁"块，供下一段使用（不进入视频提示词）：

```text
〔衔接锁·第N段结束〕
在场：A（画面左，侧身朝右，站）、B（画面右，背对门，坐）
视线：A 看 B 手中的信封；B 低头
道具：信封在 B 右手；台灯开着；门半掩
环境：夜，雨，窗外霓虹蓝紫
情绪落点：B 刚说完拒绝，A 未回应
末镜类型：双人中景
```

**写下一段时**，先读上一段衔接锁，开头二选一并在【整体叙事】首句说明：

1. **直接承接**：时间轴第一小段从衔接锁状态起幅，逐项沿用站位、朝向、道具和光线。
2. **转场缓冲**（上一段以双人/多人镜头、复杂站位或强动作收尾时优先）：第一小段先给环境空镜、第三人反应、道具特写或声音先入（如雨水沿窗滑落、门外脚步、手机亮屏），2–3 秒后再回到人物，并在回到人物时按衔接锁复写站位。空镜必须承接上一段已经发生的动作或声音，不凭空制造动静。

衔接自检（不通过就改，不交付）：

- 人数、身份、左右关系、服装状态与上一段一致，或有可见的进入/离开/移动过程；
- 道具归属、门窗、光线、时间天气一致；
- 情绪从上一段落点继续，不重置；
- 上一段末镜与本段首镜不是同一景别、同一机位的机械复制。

## 4. 打戏

段落以肢体交手、追逐搏斗、法术对抗为主时，不在本 Skill 内直接写：先调用 `fg-action-direction-card` 产出"武戏方向卡"，成员确认后交给 `wuxi-action-director-public` 写稿；写好的武戏稿外层仍补齐本格式的【参考图绑定】【声音设计 · 对白】【负面约束】和衔接锁，保持全剧格式一致。

## 5. 修改

成员说"改第 N 段……"时，在内部修改后**完整重发该段**全部字段与衔接锁；修改改变了结束状态时，提示下一段需要重新生成。

## 6. 交付前检查

- 字段齐全、顺序与标题一致；总时长与时间轴首尾吻合；
- 台词逐字来自剧本，未遗漏、未改写，语言符合圣经；
- 每个人物都绑定到已通过的资产编号；
- 没有"慢动作 / 定格 / 化作光"等会让模型停住或糊成一团的写法；
- 衔接锁已输出，且本段开头与上一段衔接锁一致或使用了转场缓冲。
