# 武戏方向卡

打戏最怕写完才发现方向不对。先用一张卡把会改变整段画面的决定问清楚，成员勾选或改一句话即可，**不写完整提示词**。

## 1. 识别

段落满足任一条即进入本流程：两人以上肢体交手；持械/徒手搏斗；追逐中的扑打；法术、能量、巨物对抗；明确写"打起来""动手"。

## 2. 方向卡内容（固定 9 项）

```text
〔武戏方向卡·第N集第M段〕
1. 题材质感：写实街头 / 写实格斗 / 动作电影（枪战、追车）/ 奇幻能量 / 东方玄幻（按圣经给默认值，并说明理由）
2. 卖点：速度型（越打越快越密）/ 力量型（越打越重，砸在实体上）/ 体量型（巨物、法相，需超远视角）——三选一
3. 双方与打法：A 用什么、怎么打；B 用什么、怎么打（每人 2–3 个招式，用看得见的动作描述）
4. 能量／特效：最多 3 种，同时出手不超过 2 种；写实题材写"无特效，只有物理冲击"
5. 节奏曲线：开场爆发 → 同一种交锋逐段加密 → 最后三分之一才升级（新机制/变大/换地点各最多一次）
6. 高潮画面：一句话（必须是某一招打出来的后果，不是局势俯瞰）
7. 结尾：终结一击 / 钩子（停在将命中的一瞬）——按剧情选择，并写清与下一段的衔接方式
8. 参考图分工：@角色N 只取人物不取背景；场景唯一出处 @场景N 或"按文字"
9. 台词与禁区：最多 1–2 句短台词（语言按圣经）；见血程度；必须避开的画面
时长与分段：本段 X 秒 → 武戏节拍 Y 段（30 秒 8 段，15 秒 4–5 段，每段 3–4 秒）
```

## 3. 默认值（海外 AI 短剧）

- 题材质感默认"写实动作电影"；只有圣经或剧本明确是奇幻/玄幻时才用能量特效。
- 卖点默认"速度型"；对手体型明显更大或剧情强调压制时用"力量型"。
- 见血：全片 1–2 次，只在改变局面时出现；平台合规需要时改为"无血腥"。
- 朝向：交锋时主角面朝对手打，镜头多在侧面、侧后方，不做正对镜头的摆拍。

## 4. 确认后

1. 按 `wuxi-action-director-public` 的规则写稿（开头只写"是什么样"、正文每段五个成分、称呼用名字不用代词、最后一行"严禁画面生成字幕。"）。
2. 外层补齐 FG 标准格式的【参考图绑定】【声音设计 · 对白】【负面约束】，并输出段间衔接锁。
3. 写实题材把 wuxi 的"能量锁定"替换为"物理冲击锁定"：冲击落点、碎裂物、扬尘水花、身体受力方向。
