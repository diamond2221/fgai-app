# 美林 · FG 超级导演 —— 设计说明（原型 v0.1）

一个不靠画布的"对话即制片"板块。成员只做两件事：**说想法、按确认**。美林负责把想法推进成剧本、资产、分段视频提示词和成片任务。本地原型先跑通「海外 AI 短剧」方向，验证后接入 FG Studio 第六板块。

## 1. 体验原则

1. **一个入口**：中央光球就是 Agent。点麦克风说话，或在底部输入框打字；不区分"工具页"。
2. **成员是审核员**：每一步由美林先给出完整方案，成员只需"确认 / 换一个 / 说一句修改意见"。
3. **航线可见**：右侧"制作航线"始终显示七个阶段与当前进度，任何阶段可回看、可重开。
4. **卡片代替画布**：每一步的产出以"决策卡"浮现在光球下方（画风卡、剧本对照、资产墙、分段时间轴、拍摄队列），看完即确认，不需要拖拽连线。
5. **诚实**：示意图、模拟任务、真实生成严格分开标注；未生成不说已生成，未知费用不写 0。

## 2. 方向与全局设定

| 方向 | 状态 | 主 Agent 全局设定（摘要） |
|---|---|---|
| 海外 AI 短剧 | 本期开放 | 竖屏 9:16、英文台词（可改）、欧美/目标市场演员面孔、强钩子开场、每集 60–120 秒、单段 15 秒、写实电影质感 |
| 贝瓦儿童短视频 | 预留 | 小河狸贝瓦 IP、3D 卡通、温暖明亮、无危险动作、儿童安全词表、中文童声 |
| 商业广告 | 预留 | 产品为主角、15/30 秒、品牌色与 Logo 规则、卖点三段式、可 TVC 化 |

每个方向对应一份"方向预设"（`server/presets.mjs`），决定默认模型、画幅、语言、可用画风、资产模板、分段时长与禁区。

## 3. 制作航线（海外 AI 短剧）

| # | 阶段 | 美林做什么 | 成员确认什么 |
|---|---|---|---|
| 1 | 立项 Brief | 把一句话/语音想法整理成题材、目标市场、集数、单集时长、主角关系；最多追问 3 个真正影响结构的问题 | 立项卡 |
| 2 | 剧集圣经 Bible | 生成 6 张画风卡（同一主角同一场景的风格示意）+ 演员面孔/地域、台词语言、表演风格、色彩、视频模型 | 选一张画风，锁定圣经 |
| 3 | 剧本 Script | 双通道：A. Google AI Studio 指引（逐步截图式说明 + 一键复制 Prompt + 粘贴回收）；B. Sonnet 5.5 直接生成。并排对照，逐集采用 | 每集采用哪一版 |
| 4 | 资产 Cast & Sets | 从已采用剧本抽取角色/场景/道具 → 按 short-drama-asset-prompts 写资产提示词（面孔按圣经）→ 出图 | 每个资产：通过 / 重生 / 上传替换 |
| 5 | 分段 Segments | 按剧情转折把一集切成 15 秒单元；每段用 FG 文戏导演 Skill 写成标准格式提示词；段间"衔接锁"保证站位与状态连续；检测到打戏先出"武戏方向卡" | 每段提示词（可一句话修改） |
| 6 | 拍摄 Shoot | 单个或批量提交；建议先 480P 看节奏，再 720P 正式；显示人民币估算与任务编号 | 提交范围、分辨率 |
| 7 | 后期 Post | 台词随视频生成；导出 SRT 字幕；给出 Suno 音乐生成指引（公司 Gmail 账号，人工过验证码）；剪辑清单 | 完成 |

## 4. 超级大脑（编排）

```
成员语音/文字 ──► 意图解析(Sonnet 5.5) ──► 阶段状态机 ──► 技能执行器 ──► 决策卡
                         ▲                          │
                         └──── 项目记忆（圣经/剧本/资产/段落/任务）◄──┘
```

- **主模型**：WeToken `claude-sonnet-5-5`（用户可切换 Opus 5.5 / GPT-6 Astra / DeepSeek V4 Pro）。
- **技能执行器**：每个阶段绑定固定 Skill 与输出合同：
  - 立项/剧本：剧本 Prompt 包（本仓库 `skills/fg-overseas-drama-script/`）
  - 资产：`short-drama-asset-prompts`（海外面孔覆盖默认东亚设定）
  - 分段：`skills/fg-drama-video-prompt/`（由 script-to-drama-prompt-dev 派生，输出 FG 标准格式 + 衔接锁）
  - 打戏：`skills/fg-action-direction-card/`（先出方向卡，确认后交给 wuxi-action-director-public 写稿）
- **项目记忆**：剧集圣经是唯一事实来源；每段提示词生成时注入圣经、本集剧本、出场资产编号、上一段结束状态。
- **意图路由**：自由对话里识别"改第3段的台词""这个角色换成金发""全部批量生成 480P"等指令，直接落到对应对象，不要求成员找按钮。

## 5. 段间衔接锁

每段生成后抽取 **结束状态**：在场人物、站位与朝向、视线、手中道具、门窗光线、情绪落点。下一段开头必须二选一：

1. **直接承接**：从结束状态原样起幅（人物站位逐项复写）。
2. **转场缓冲**：上一段以双人/多人镜头结尾时，下一段首镜优先用环境空镜、第三人反应、道具特写或声音先入，再回到人物——用来吸收模型在人物连续性上的误差。

衔接锁同时检查：人物数量、左右关系、服装状态、道具归属、时间天气是否一致；不一致时标红并给出修正建议。

## 6. 视觉与形象

- **美林光球**：WebGL 自定义着色器——玻璃质感球壳（菲涅耳边缘 + 薄膜干涉彩虹）包裹流动的液态光核（3D 噪声域扭曲），外加辉光后处理与漂浮光尘。状态：待机（缓慢呼吸）、聆听（随麦克风音量起伏）、思考（光核加速旋流、色温变冷）、表达（随输出节奏脉动）。
- **界面**：深色电影感底色 + 毛玻璃面板（backdrop-filter）+ 细边高光；中文用苹方/思源黑体，英文用 Inter；动效遵循 `prefers-reduced-motion`。
- **为什么不用 Hyper3D/Blender 实时模型**：网页端需要实时响应语音和状态，着色器球体体积小、加载快、可随状态连续变化；Blender 适合后续制作宣传片或静态海报。

## 7. 接入 FG Studio（第二阶段）

| 原型 | FG 正式 |
|---|---|
| 本地 Node 编排服务 | 第六板块网关模块 `fg-director.mjs`（复用 FG 登录、按账号隔离） |
| 本地 JSON 项目存储 | 原生后端 PostgreSQL（项目/段落/任务表 + 迁移）+ NAS 媒体 |
| 浏览器 Web Speech | 公司火山流式识别 `/api/fg/speech/stream` |
| 模拟出图/出视频 | 原生 `/api/tasks`（WeToken 渠道、人民币报价、费用核销、任务恢复） |
| 本地页面 | 画布 web 新路由 `/director` + 侧栏"超级导演" |

费用、权限、回收站、审批全部复用现有链路，不另起一套。

## 8. 原型范围与边界

- 已实现：完整界面与七阶段流程、光球形象与四种状态、语音输入（浏览器支持时）、朗读回复、模拟模式全流程、真实模式文本调用（配置 WeToken Key 后）、SRT 与提示词导出。
- 模拟：出图与出视频在原型中为示意，不调用付费接口。
- 未实现：真实出图/出视频、账号与费用、Suno 自动化（Suno 验证码须人工）。

## v0.2 更新（2026-10-14）

### 名字与结构
- 板块更名为 **美林 · MEILIN**。
- 信息结构改为 **剧 → 集**：首页是"我的剧"海报墙；进入一部剧后，剧集层负责「立项 → 圣经与画风 → 主资产」，之后是 30 集的剧集墙；点开某一集，单集层负责「剧本 → 本集资产 → 分段提示词 → 拍摄 → 后期」。主资产全剧复用，每集只为新出现的角色、场景、道具出图。

### 模型（与 FG 工作台同一份清单）
- 主脑：Claude Sonnet 5.5（默认）/ Opus 5.5 / GPT 6 Astra / GPT 5.6 Sol / DeepSeek V4 Pro。
- 出图：GPT Image 2（默认）/ 2.5 Flare / 2.5 Sunburst / Seedream 5 Pro / Seedream 5 Lite / Gemini 3 Pro Image / Gemini 3.1 Flash Image / Wan 2.7 Image。
- 出片：SD2.5（默认）/ SD2 / SD2-fast / SD2-mini / Wan 3.0 / MiniMax H3 / HappyHorse 1.1（参考、图生、文生）。
- 参数（尺寸、质量、分辨率、时长、画幅、参考上限、是否同步音频）由 FG 网关的 `fg-model-capabilities.mjs` 计算，原样复制到 `server/fg/`，与生产一致。每个资产、每次出片都可以单独换模型。

### 技能
- 按阶段选择：剧本、画风解析、资产提示词、分段导演、打戏、增强（可多选，例如 ZY 电影感、表演指导）。
- 技能直接读取这台电脑 `~/.claude/skills` 里已安装的版本，不复制进仓库；实时模式下按阶段装进主脑提示词，ZY 只加载当前用途需要的参考文件（Dream Decode / 电影感编译）。
- ZY 造梦师是 CC BY-NC 4.0，商用前需取得作者授权；界面已标注。

### 画风来源
1. 海外预设（8 套，使用 FG 风格库示例帧）；2. FG 画布风格库（18 套，原样复用其规范文本）；3. FG 灵感库（读取画布 `web/public/inspirations`，本机有 FG 项目时自动连接）；4. 上传 1–6 张参考图 → ZY Dream Decode 解析为全剧画风规范（模拟模式只提取色板）。

### 上传
- 画风参考图、资产定妆照（新建或替换版本）、剧本文件（.docx / .txt / .md / .srt / .fountain）。

### 星球视图
- 资产与成片都可以切到"星球"：图片按纬度排在球体内侧，相机在球心；拖动旋转，滚轮钻进，点击打开。资产按角色 / 场景 / 道具分类，成片按本集 / 全剧分类。

### 对话即操作
- 所有按钮动作都能用一句话完成：换模型（"出图换成 Seedream 5 Pro"）、给单个资产换模型重出（"Ava 用 GPT Image 2 重新生成"）、选技能（"开启 ZY 电影感""分段用 CineDance"）、换画风（"换成霓虹黑帮""用我上传的图做画风"）、切集（"打开第 3 集""写第 2 集"）、改段落、出片、改规格（"改成 50 集，每集 60 秒"）。实时模式下由主脑输出动作序列执行。

### 与 FG Studio 的复用 / 联动
| 美林 | 复用的 FG 能力 |
|---|---|
| 模型清单与参数 | 网关 `fg-model-capabilities.mjs`、画布 `fg-model-names.ts` |
| 画风 | 画布 `canvas-style-picker-modal.tsx` 风格库、`canvas-style-system.ts`（四维组合，贝瓦/广告方向启用）、`style-profile.ts`（参考图资产，接入后存为用户画风） |
| 灵感库 | 画布 `public/inspirations/*.json` 与缩略图 |
| 出图出片 | 接入后走画布 `generation-task.ts` → 原生 `/api/tasks`、任务中心与人民币报价 |
| 资产 | 接入后写入画布资产库（`resources.ts` / NAS） |
| 语音 | `/api/fg/speech/stream` |

## v0.3 调整（按成员反馈）

### 流程：先剧本，后资产
- 立项 → 圣经与画风 → 进入剧集。每一集先定剧本，再按这一集剧本抽出角色、场景、道具。
- **全剧资产库**：任何一集出过并通过的资产都进库；后面的集数先查库，已有的直接复用，只给新出现的出图。库里每个资产标注"用于第几集"，可按集筛选。
- 资产提示词统一由 `short-drama-asset-prompts` 编写；出图时另选 **风格技能**（新阶段 `render`）：原样出图 / ZY 电影感 / DeepWhite 静帧 / Lira 人像 / GPT Image 2 风格库。可设全剧默认，也可每个资产单独选；每个版本记录用的模型和风格技能。

### 立项卡
- 集数、单集时长改为自由填写（1–300 集，15–600 秒），实时算出全剧时长；锁定后也能改，或直接说"改成 50 集，每集 60 秒"。
- 每个问题（如"女主的反击方式"）都可以"自己写"答案。

### 出图尺寸
- 所有生图模型默认 16:9 横版，按各模型自己的尺寸表取值（GPT Image 系列 1536×864，Seedream 与 Wan 取各自尺寸表里的 16:9 档，Gemini 用比例 16:9 · 2K）。设置抽屉里尺寸标出比例。

### 每部剧一个独立导演（记忆）
- 每部剧有自己的记忆：流程里定下的决定（立项、画风、模型、技能、每集剧本与入库资产）自动记录，同一主题只保留最新一条；成员说"记住……/以后……/每一集都……"记为成员要求，"忘掉……"删除。
- 实时模式下记忆和最近 30 条对话一起进入主脑上下文；侧栏"记忆"页可查看、添加、删除。

### 界面（白天版）
- 浅色"光学实验室"：瓷白底 + 细点阵、墨色文字、单一群青强调色；只有美林的光球是彩色全息的。
- 布局：悬浮玻璃顶栏与左侧流程栏；每个阶段是"吸顶标题 + 取景框面板"，推进动作放在标题右侧；底部是美林的对话坞（光球 + 输入 + 最新回复气泡，自动收起）；右侧可展开"对话 / 记忆"。
- 星球视图的全屏改为挂到页面根节点（portal），真正铺满整个窗口，Esc 退出。

## v0.4.1：v0.3 的外观 + 后续细节（2026-10-15）

v0.4（贾维斯式 HUD）和 v0.5（导演台 / 3D 摄影棚）两版界面都撤回，外观和布局回到 v0.3：浮动玻璃顶栏、左侧流程栏、底部对话坞（光球 + 自动收起的回复气泡）、右侧 对话 / 记忆 抽屉、白天主题。后面提的细节全部保留在这套外观上。

### 记忆
- 左侧流程栏"全剧"下新增**长期记忆**入口（剧集页和每一集里都有）：按制片规则 / 你的要求 / 立项 / 画风与技能 / 模型 / 每集决定分组；点任意一条直接改，过时的可以忘掉；顶部可以直接加一条。
- 顶栏的记忆抽屉也能改：点一条就地编辑（回车保存，Esc 取消），制片规则和你的要求排在最前；抽屉里有"打开完整记忆页"。
- 改过的流程决定会变成"你的要求"并标"已修改"。
- 每部剧自带一条制片规则（可改不可删）：**成片声音：视频只随片生成音效、对白和旁白，不带背景音乐、不带字幕；BGM 和字幕都在后期加**。分段提示词的【声音设计】与【负面约束】、出片任务说明都按这条写。

### 剧集
- 剧集页网格上方一条"全剧 N 集，每集约 M 秒"，点"改集数和时长"就地改；集数不能少于已经开始做的最后一集。
- 每一集右上角 ⋯：**在后面插入一集**（后面的集顺延）、**删除这一集**（要点两次；剧本、分段和成片记录一起删，后面的集往前补位；这一集新建的资产留在全剧资产库）。网格最后一格是"+ 加一集"。
- 插入和删除时，记忆里流程记下的"第 N 集……"会跟着改号；你自己写的要求不动。
- 对话里也可以说："第 3 集后面加一集""删掉第 5 集""加一集""全剧改成 60 集"。

### 分段
- 每段时长**按剧情定**：10–25 秒之间，且不超过出片模型上限（SD2.5 / Wan 3.0 最长 30 秒 → 10–25 秒；SD2 / MiniMax / HappyHorse 最长 15 秒 → 10–15 秒）。示例第 1 集切成 18 / 14 / 20 / 15 / 12 / 11 秒；换出片模型会自动重新适配还没拍的段落。工具条显示"SD2.5 · 每段 10–25 秒"和"随片：音效 · 对白 · 旁白"。
- 每段自动挂**参考图**（出场人物 + 场景 + 道具），提示词【参考图绑定】只用 @代号 引用这些；分段列表右侧的小头像就是这一段会上传的图。点开一段可以增删、调顺序（"+ 挂一张"从全剧资产里选），超过模型上限的会标红不上传。实时模式下改了参考图，这一段会标"待重写"。
- 分段导演默认 **剧本转文戏**，输出仍是 FG 视频提示词格式（【视频整体概念】…【负面约束】+ 衔接锁）；可选 FG 文戏导演、CineDance。打戏用 **武戏导演**。

### 技能清单
- 去掉：DeepWhite 编剧、DeepWhite 导演分镜、Seedance Director、Seedance 情绪导演、Video Blueprint；"剧本转文戏"去掉作者名和许可文字；"武戏导演"去掉"公开版"。

### 资产
- 资产详情里点名字旁的笔可以**改名字**（含中文名），右下**删除**要点两次确认；删除会从各集资产列表和分段参考图里一起摘掉。对话里也可以说"角色7 改名叫 Ivy""删掉道具3"。
- 上传的图如果是相机或聊天导出的乱码文件名，自动起名"新角色 7"之类，随时可改。

### 接口（给后续接入用）
- 每次 `/api/dramas/:id/act` 和对话回复都带 `trace`（这次读了几条记忆、用了哪个技能和模型、遵守了哪条规则）和 `next`（建议的下一步）；`GET /api/dramas/:id/next?episode=` 单独取建议。当前界面暂不展示，留给以后。
