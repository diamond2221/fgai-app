# 1.3.3 — 故事协作、NAS 删除归档与费用核对

## 交付范围

- 共享故事项目仅管理员可删除，原记录加归档标记，关联画布及分享链接退出工作区；费用及复用素材保留。删除前将聚合记录保存到 `FgStudio/recycle/projects`，成功后释放故事的选用状态。
- 故事库根据未归档的真实项目显示选用状态，取消种子数据中的预填人员。新增管理员编辑、删除、版本冲突检查；全公司同一个故事只允许一个有效立项，已选故事无法再次立项。
- 制作项目按级别、小组、负责人筛选；短剧区分私人短剧与共享故事，管理员只能管理本人及普通用户私人内容，其他管理员私人内容继续隔离。
- 小说、综合工作台运行容器仍仅挂载本账户目录。内部能力签名加服务器会话保护归档接口，后端只接受模块、目录名和操作标识，在已有 NAS 根挂载内执行 rename，避免跨挂载 EXDEV 及 SMB deferred unlink。移动前后校验文件哈希与目录清单；归档、回滚均不跟随符号链接，禁止跨账户、路径穿越及覆盖现有工程。
- 素材删除前保存业务记录；本地文件通过持久化 outbox 移到 `recycle/resources`，公司素材发布记录保存在 `recycle/company-assets`。共享对象保留。原有独立画布 30 天回收站不变。
- WeToken 每分钟同步费用及详细用量，编号精确匹配优先；对编号不同的文本请求，要求完整输入、输出、缓存读取、缓存创建、同模型、语义及相近完成时间，并且两边均唯一。只采用官方账单实际金额，记录原始参考编号和证据，人工处理优先。失败且缺少用量证据的请求不推测收费或零费用。

## 数据与 API

- 原生迁移 52 增加 `projects.fg_deleted_at`；FG 扩展增加 `fg_story_projects.archived_at`、有效选题唯一索引、`fg_topic_overrides`、`fg_fee_usage_matches`。
- 管理员 `PUT/DELETE /api/fg/topics/:id`，删除须携带当前 revision，已立项故事必须先删除项目。
- 内部 `/api/fg-project-files` 与 `/api/fg-story-archive` 由网关阻止公开调用，后端额外校验共享密钥及用户会话。
- NAS 不可用、归档冲突或任务活动中时保留原始内容。资源 outbox 保存重试状态，避免逻辑记录删除成功后丢失物理清理任务。
