# 1.3.7 模型参数与画布交互

本轮先修复 1.3.6 验收后的四个问题。后续全模型官方参数审计、画风参考图与导演 Prompt 合同属于接续任务，不在本版本宣称完成。

- GPT Image 2 / 2.5 的目录实际包含 1536×864 与 864×1536，前端继承的旧像素表却过滤了这些尺寸。现在从当前目录尺寸构造预设，保留明确配置的模型专用预设。
- Seedance 2.5 执行插件的固定 9/3/3 限制改为按请求模型选择 30/10/10；旧模型保留 9/3/3。浏览器协议提交也校验数量并完整传递，不截断素材。
- 资产生成弹窗的关闭与提交状态分离，× 和关闭按钮在提交时仍可使用；已授权的队列继续执行，生成按钮保留 busy 状态。
- 真实画布复现：展开编辑弹窗 z-index 为 1200，@菜单为 1000，被弹窗遮挡。引用菜单现在按所在弹窗层级显示到其上方，不修改全局弹窗样式。

官方合同：[OpenAI Create image](https://developers.openai.com/api/reference/resources/images/methods/generate)、[Seedance 2.5](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)、[Seedance 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)。

专项验收：图片尺寸控件与视频 API 合同 32 项测试通过；Go 实际打包插件的 30 图及 31 图拒绝测试通过。上线后还需核对实际页面、版本与部署插件内容。
