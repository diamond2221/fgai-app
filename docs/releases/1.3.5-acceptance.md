# FG 1.3.5：工作台与影视剧作工坊发布验收

## 范围

基于 `08fb413b7` 的画布 v1.6.8.1 同步，保留 FG 登录、管理员私人内容隔离、共享故事、NAS、预算、人民币账单和既有 Agent。新增图片/视频工作台、118 项工具与预设、影视剧作工坊知识包、个人头像、登录日志及图片参数合同。

工作台接入 FG 人民币报价组件，避免积分关闭时仍显示“预估可用积分”。公司模型继续走原生任务入口和执行前 FG 预算准入，不启用上游游客、积分或独立密码/邮箱管理。

回收 Mac 维护任务安装器为可审查源码。任务已加载时不改 plist、不重启；明确禁用或无法确定状态时拒绝安装，仅注册缺失且未禁用的任务。发布不得停用生产 LaunchAgent。

## 数据与回滚

原生 schema 53 升至 57：54 个人资料安全、55 系统头像、56 登录日志、57 工作台与预设。必须先用实际生产快照隔离演练并校验原表原字段，发布前另存最新快照。旧后端不能读取升级后的 schema，回滚须同时恢复升级前数据库和对应镜像。

## 验证记录

- 安装器 4 项模拟回归通过：已加载不触碰、明确禁用拒绝、状态未知拒绝、缺失任务只 bootstrap。
- 人民币报价、入口与历史删除 12 项专项通过；TypeScript 与正式 `/fg-six/` 前端构建通过。
- Linux ARM64：补齐新插件、Agent 依赖和 zip 构建工具后，database、workbench、app、handler、platform、repository、skills、protocol 八个受影响包完整测试通过（包含原支付插件二进制断言，没有删除或跳过）。后端与迁移程序构建通过。
- 工作台目录/恢复/功能闸门与图片参数前端 22 项专项通过；公司网关 167 项非付费测试通过。
- 实际生产快照在独立 PostgreSQL 17 容器和内部网络完成 53→57、重复执行和 verify；139 张原表的原字段、行数和行摘要完全一致。升级前演练备份 22,032,037 bytes，经归档目录校验；旧镜像拒绝 schema 57 的回滚边界已验证。

本版不额外调用付费模型；工具入口、权限、报价与任务校验的验证不代表 118 项工具全部生成过。广告、小说、综合工作台整条剪辑导出验收及 Suno 登录问题仍保留原有边界。
