## 音频与语音工具

- Seed Audio：提示词生成声音，隐藏 Alloy、音色、速度与语音说明等 TTS 专用设置；输出 mp3 / wav。
- 豆包语音 2.0：显示公司中文音色名，清理旧 Alloy 默认值；语速与格式按语音接口规范处理。
- 实时语音识别、录音文件识别、语音翻译属于工具，入口在音频设置区；不注册成图片／视频／音频生成模型。
- Suno：公司账号制作队列，明确任务编号和排队／处理中／归档／可播放状态，作品完成后可添加到画布。验证码由真人在官网处理，当前不能宣称无人值守自动生成通过。

已真实生成 Seed Audio 与豆包语音 MP3，保留操作编号与文件解码证据；发布后的节点保存、重载和播放需要独立验收，不重复付费生成同一测试。

能力配置测试覆盖所有已配置模型并拒绝供应商目录参数覆盖，前后端校验非法边界。文档核验不等于所有参数组合付费生成过。H3 精确公开 API 引用边界、供应商别名实际路由，以及未开放功能继续记录为待核实，不能标作“全部模型全部参数已实测通过”。
