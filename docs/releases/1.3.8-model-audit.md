# 1.3.8 模型参数复核（2026-10-14）

范围：现有23条WeToken模型线路、Seed Audio与豆包TTS、3项语音工具。逐模型检查参数档案与实际执行插件，区分官方能力、FG已开放功能、供应商别名、平台传输限制。不改变密钥、线路、开关和既有人民币费率。不将产品宣传页当作完整API合同。

## 本轮变化

- Seedance各版本默认分辨率720p；官方默认比例adaptive，FG在普通文生/参考任务显式默认16:9以确定费用，保留adaptive选择；严格首帧/首尾帧仍强制adaptive。2.5仍30图/10视频/10音频，2.0仍9/3/3，Fast/Mini不增加1080p或4K。
- HappyHorse默认分辨率1080P；I2V仅跟随首帧，实际API不发送ratio。T2V/R2V继续各自支持的比例和参考数量。
- DeepSeek V4 Pro精确上下文1048576，输出393216，文本输入，保留官方类型限制。
- 新导演格式按目标视频模型的提示词上限生成，超长拒绝覆盖旧分镜；中文HappyHorse上限2500，不能无差别提交长模板。
- 1.3.7已修复GPT2/2.5像素目录与Seedance执行插件的版本漂移，本轮继续回归。

## 音频与语音

豆包TTS2.0：官方speech_rate -50～100对应0.5～2倍速，MP3/WAV输出；FG WAV由PCM封装，并验证音频内容。官方另支持PCM/OGG等，当前未开放的格式不展示为可用。

实时ASR、录音ASR、语音同传保留工具属性，不冒充生成模型。录音识别极速版官方100MB、2小时，wav/mp3/ogg opus；FG所用常规异步线路须按自己的合同，不混用极速版参数。翻译语言需按当前服务实际支持范围。

Seed Audio现有MP3/WAV生成已在1.3.4验证；本轮公共搜索未找到与当前`/api/v3/tts/create`路由完全匹配的公开参数页，3000字符上限保留为当前接口适配限制，不能称已重新获得完整官方确认。Suno使用公司账号队列，验证码由真人处理；没有把账号网站参数复制成官方API保证。
