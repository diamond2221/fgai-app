# 1.3.14 美林交互与项目协作

## 范围

第六板块美林删除入口、操作反馈、模型正文增量、已有剧本直接导入、默认爆款短剧工厂、分集内设定编辑入口，以及管理员帮成员制作后的项目素材访问。个人 Key 与未关联的私人资源继续隔离。

## 诊断依据

- 成员失败任务引用两张管理员拥有的图片；图片已通过 asset_representations 和 project_asset_links 绑定到成员短剧项目，但旧资源范围只考虑拥有者及全公司共享项目，导致读取失败。
- 新资源范围依据已持久化的项目资产关联或镜头产物关联，并复用项目可见范围。任务、预览和生成参考使用同一资源校验。删除项目或撤销关联后不继续授权；未绑定私人素材不开放。
- Docker 默认 DNS 对 asset.wetoken.ai 返回 ENOTFOUND，三组公共 DNS 均能返回有效公网地址。只调整生成后端 DNS；不改供应商域名、不绕过出站地址安全校验、不硬编码供应商 IP。
- API 调用日志中的请求成功不等于任务完成。未对既有失败任务自动重提，不将超时任务强行标记为成功。

## 实现与验证

- 美林用现有稳定操作 ID；SSE 先发 status，按原任务文本增量发送正文，JSON 动作在完整解析和保存后才能执行/显示为完成。断连不创建第二个付费任务。
- 原稿导入只保存用户内容，不调用模型立项。后续提取资产仍由用户主动选择。
- 角色和图片按项目资产绑定授权；视频按镜头产物绑定授权。专项测试覆盖项目所有者读取管理员产物，以及无关成员仍被拒绝。
- Node 模拟接口测试覆盖真实增量转发、事件流最终文档、原稿不触发模型、原稿防覆盖、修改圣经保留原稿。付费模型与媒体验收未运行。
- 部署前运行 Linux CGO 权限测试与生产构建；上线证据在发布完成后补充。
