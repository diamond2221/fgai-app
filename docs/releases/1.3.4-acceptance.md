# FG 1.3.4 验收记录

日期：2026-10-12。发布前源码与构建验证、发布后实机验证分开记录。

## 本次变更

- 修正项目角色的读取、编辑和图片绑定权限与项目访问权限不一致的问题；保存角色新版本时同步发布共享项目的绑定图片权限，保持管理员私人项目与未关联角色的隔离。费用预览按系统渠道作用域判断，不依赖已隐藏的供应商展示名。
- 角色三视图提交前提供模型、尺寸、质量及费用预览；从所选图片模型的有效默认值开始，不继承画布残留的空自定义尺寸。支持直接上传三视图和选取不在本地缓存的远端图片；绑定不再强制同步整个素材库。
- 恢复新用户导演工作区的后台准备；小说和综合工作台目录通过经过校验的 Docker NAS 挂载创建，避免 macOS 定时服务缺少交互登录的卷访问权限。实机后台状态连续采集为 ready；原用户工程及私有卷保留。

- 故事投稿：完整详情、待审／通过入库／退回原因、撤回入库、审核记录及归档删除。对已选故事限制撤回与删除，要求先处理制作项目；版本与事务锁防止并发覆盖。
- 管理员短剧筛选改为“本人及普通用户”，其他管理员私人内容保持隔离；故事项目保持共享。
- Seed Audio 隐藏 TTS 专用参数；豆包语音中文音色、历史 Alloy 默认值归一化。
- Suno 提交结果、原任务状态、可播放作品和画布添加入口；关闭页面保留任务，按原编号查询而非仅依赖最近 60 个队列条目。
- 独立官方模型能力配置；Wan3 30 秒及输入输出共享时长预算；图片分辨率、质量、参考数量与 Wan 编辑 2K 限制。
- 画布与综合工作台上游同步；小说来源记录对齐已包含代码。
