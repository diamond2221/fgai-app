# FG 超级工作台本周更新｜10 月 7 日—10 月 15 日

这周 FG 超级工作台从 **v1.3.0 持续更新到 v1.3.16**。这次把新增功能和影响大家使用的修复放在一起说，欢迎大家用真实制作流程试一试。

1. **新增「美林 · 超级导演」**。在 FG 超级工作台左侧，与「短剧 Agent」「广告工作台」平级。可以边做边和 AI 对话，调整故事方向、剧本、角色、画风和拍摄内容。

2. **两种短剧制作方式同时保留**。美林更偏对话共创，适合一边讨论一边修改；短剧 Agent 更偏工程化制作，章节、镜头、资产、产物版本集中管理，适合持续推进和多人接续。大家可以用同一段剧本对比哪种更顺手。

3. **美林支持已有剧本直接开始制作**。可以粘贴或上传自己的剧本，不必重新走 AI 立项问答；从零创作默认使用爆款短剧工厂，也保留 Google AI Studio 起草、导入和修改的方式。

4. **美林的项目设定可以修改了**。立项卡、剧集圣经、选角、表演要求和全局画风可编辑；新生成的设定说明以中文为主，英文角色原名和英文对白要求可以保留。修改设定不会自动把已有图片、视频重生成。

5. **美林的剧集管理与等待反馈补齐**。支持调整总集数和单集时长、插入或删除某一集、末尾加集，也可通过对话提出修改；集号及流程记忆会相应调整。首页可以删除自己的剧，操作时及时显示等待状态，AI 回复逐步显示，减少点了以后不知道有没有反应的情况。

6. **GPT 改为个人接入**。个人设置里新增 GPT 接入，填写自己的 API 地址和 Key，默认使用 Trings 的 GPT 6.1 Sol、high 思考。个人 Trings 用量不扣 FG 内部额度，上游费用和剩余额度以个人账户为准；图片模型仍保留 WeToken。

7. **短剧文本有默认备用模型**。已绑定个人 Key 时优先用 GPT 6.1 Sol，未绑定时用 Sonnet 5.5；明确额度不足时回退一次到 Sonnet 5.5，按公司额度计费。超时或已经输出部分内容时，不会盲目换模型重做。

8. **短剧资产生成更统一**。加强角色身份、物种、服装、材质、配色和项目全局画风的约束，角色定妆、无人场景、单件道具分别处理，减少同一项目各张图风格差得太远的问题。生成前可以检查、修改实际提示词。

9. **角色、场景和道具支持批量确认与生图**。可以统一选模型和规格，也可以逐项改提示词及参考图，查看单项与合计报价；仍可只确认资产、只保存提示词。新项目默认图片 Image 2.5，视频 Seedance 2.5／480P，项目已经选好的模型保留。

10. **自定义画风与参考图保存修复**。画风参考图改为可选上传 0—6 张；修复带参考图保存失败、提示保存成功但“我的风格”里找不到，以及重新打开后丢失的问题。资产生成继续继承项目画风，生图时也可选择已有风格技能。

11. **剧本到分镜的制作规划更完整**。可以选择目标视频模型、片段时长，以及按剧情或固定时长拆分；较长章节的输出截断、换行重复转义、旧表格粘贴后镜头分隔丢失等问题一起修复。

12. **视频提示词加强导演细节**。补充参考图分工、人物站位、动作先后、摄影机路线、焦点、时间轴、声音和前后段承接。进一步压缩无意义等待，加强动作速率、自然反应、受击和小魔法的因果过程；实际成片节奏和穿帮情况仍请大家重点反馈。

13. **视频提示词可以按修改意见重写**。填写“节奏更快”“调整运镜”等具体意见，也可补选技能，先看新的完整草稿再决定应用。分镜图、黑白动作预演和视频的完整提示词可查看，历史生成时的提示词也可追溯。

14. **章节与镜头减少重复点选**。剧情章节新增批量提取角色、场景和必要道具，以及批量生成分镜／视频提示词；分镜制作新增镜头视频批量提交。生成前核对参考、规格、逐项报价、合计及剩余额度，保留逐章、逐镜操作。

15. **参考资产和产物名称更清楚**。优先匹配当前片段需要的角色、场景和必要道具，保留人工检查入口。新产物按“镜头01-分镜图-v1”“镜头01-动作预演-v1”“镜头01-镜头视频-v1”等名称登记，方便从资产栏区分。

16. **首页与灵感库融合**。保留原来的小球和上方创作区，下方加入最近画布与灵感内容，历史对话入口放在创作区右上方；修复部分灵感封面不可用、最近画布及自由画布列表预览空白的问题。

17. **新增可选「星球漫游」**。默认仍按列表浏览，也可以切换到更密集的沉浸式图片墙，拖动环顾、滚动靠近、全屏查看，并按图片／视频及分类筛选。全屏内点击作品直接看详情，不必退出到外层页面。

18. **自由画布的编辑与后台等待改善**。图片生成窗口关闭后任务可继续在后台处理；放大提示词后仍可引用资产。本次补修右下角视频参数被遮罩挡住的问题，放大状态下也可调整清晰度、比例和时长；拖动节点靠近画布边缘时会自动平移，方便挪到更远的位置。

19. **视频、音频引用与提取修复**。视频支持文生视频、全能参考、首尾帧等模式，并按实际素材校验；上传音频保留名称，@ 引用时更容易辨认。音频提取和视频截取改用预览读到的真实时长，修正“结束时间超过视频时长”的误报，欢迎重点复测。

20. **生成失败、恢复与协作问题修复**。修复部分参考素材读取失败及域名解析失败；管理员在成员项目里绑定、生成的素材和视频，成员可继续读取和制作。长任务尽量沿原任务恢复，避免重复提交；旧章节结果不再反复覆盖现有分镜。

21. **创作工具与公司技能扩充**。增加图片／视频工作台、118 项工具与预设、影视剧作工坊知识包，并接入完整公司技能包。综合工作台和小说转视频继续使用 FG 的模型、素材、费用和个人工程，保留原有 Agent 小球。

22. **广告、小说与综合工作台一批流程修复**。包括广告助手卡在结构化输出或继续任务、草稿不能填回表单、已完成产物不能打开；小说工作台首次启动、风格封面、项目创建响应丢失及任务恢复；综合工作台的低清短时长规格、媒体下载和公司技能读取。复杂 Agent 流程仍请边用边反馈。

23. **剧本导入与故事项目管理改善**。支持 Word、Excel、PDF、TXT、Markdown、CSV 等导入，增加原文／排版预览和整理排版入口；故事库可以区分已选、未选，制作项目可筛选。投稿补齐详情、审核意见和历史，减少重复立项及误建空白项目。

24. **删除、分享与回收更可靠**。修复故事、短剧、广告、小说和画布的部分删除／归档失败；画布回收站保留 30 天，可恢复或确认彻底删除，仍被其他项目使用的素材及费用历史保留。分享画布可另存个人副本；删除对话后刷新又出现、审批状态串到其他画布等问题已修复。

25. **模型参数、报价和费用说明更准确**。尺寸、比例、质量、时长和参考素材数量按实际模型／渠道区分；图片和视频展示人民币报价，批量展示合计。账单继续核对供应商实际用量，费用不明确时明确标注，失败和恢复不会随意自动重新收费。

26. **界面和服务稳定性一起补强**。改善玻璃界面的文字与图表对比、菜单滚动、弹窗截断、剪辑区透底叠字等；修复过期资源路径引起的白屏、部分保存失败、首次打开卡住，以及 NAS 重连和报表更新问题。更新日志也已补齐，方便大家查看每版变化。

27. **请重点对比测试短剧 Agent 和美林**。建议用同一段 30—60 秒剧本分别走一遍：改设定 → 提取资产 → 出分镜 → 改视频提示词 → 生成与查看产物。重点看交互是否顺手、画风和身份是否一致、节奏是否够快、动作与运镜是否自然，以及前后段是否穿帮。

28. **遇到问题请把过程反馈给我**。最好带上项目／剧名、使用入口、模型与规格、操作步骤、预期和实际结果、截图或任务编号；也请反馈哪些步骤重复、哪些功能不需要。生成失败先保留任务编号，不要连续反复提交；新功能开放试用不代表所有复杂流程和成片效果都已验收。

29. **GPT 主脑这项原计划已提前落地**。此前说要把 GPT 6.1 接给美林做大脑，现在已经按个人 Trings Key 接入，不再列为尚未完成的下一步；后续继续打磨它与项目设定、长期记忆和制作流程的配合。

30. **下一步有两个方向，先看大家有没有真实需求**。一个是视频深度参考：尝试将参考视频处理为黑白／结构信息，再用于参考生视频，重点保留动作和运镜；另一个是通过 MCP 连接 Blender，尝试和 GPT 对话完成基础建模、摆场景或预演。这两项还没定要做，效果、稳定性和投入都需要验证；大家有需求请说清具体用途，没需求就先不做。
