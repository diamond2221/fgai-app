# 1.3.6 发布验收

## 变更与边界

- 短剧资产支持批量确认、统一模型和图像规格、逐项编辑提示词、选择或上传参考图、保存草稿以及单项/合计人民币报价。生成按两项并发提交到原后台队列，完成后自动绑定新版本；失败不自动重试。
- 提示词遵循 short-drama-asset-prompts 的身份、物种和参考约束，保留项目完整全局画风。历史图片没有提示词记录时明确标为重新生成草稿。分镜继续使用 script-to-drama-prompt-dev，未切换 ZY。
- 分镜参考图的占位 MIME `image/*` 不再误报不支持；资源水合后以资源库实际 MIME 再校验，真实不支持格式仍拒绝。
- 小说工作台风格图片恢复代理路由；创建写请求延长超时，客户端保持稳定项目标识。请求结果不明确时只读查询同一项目，核对标题后才确认成功，不自动重复 POST。
- 本版没有数据库迁移，继续使用 schema 57。不调整账本、权限、供应商计费规则或生产守护任务。

## 已运行验证

- Go Linux ARM64：`internal/app` 与 `internal/protocol` 全包通过，包括占位 MIME、真实 MIME 和拒绝不支持格式的回归测试。
- 画布：7 个相关文件共 27 项测试通过；类型检查、正式 `/fg-six/` 构建及入口资源合同检查通过。
- 网关：全量 167 项测试通过。
- 小说前端：类型、lint、knip、全量 Vitest 闸门通过，272 个文件共 3,573 项用例通过。使用原产品测试品牌、双 worker、每个 VM 512MB 与 20 秒用例超时；Windows 默认并发的超时及单 worker VM 异常退出均没有跳过用例，最终全量通过。
- 小说前端：FG 品牌与 `/fg-director/` 正式构建通过；创建失败后重试保持同一项目标识的测试通过。
